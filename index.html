    ⚙️ Cài đặt

    Cập nhật Database sản phẩm

    Tải lên file Excel dữ liệu gốc (Group, Category, Sub Category, Product ID, Short Name, Base Upc) để cập nhật danh mục tra cứu Barcode / Tên sản phẩm.

    Cập nhật Return Policy

    Tải lên file Excel chính sách đổi trả. Trang tự tìm sheet Return Policy, đọc các cột Product Name, Requirement (và Product ID nếu có). Backend tự đối chiếu với danh mục sản phẩm để gán chính sách đổi trả.
